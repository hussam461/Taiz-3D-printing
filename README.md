# Taiz 3D Printing Store

متجر إلكتروني عربي للطباعة ثلاثية الأبعاد، يتيح للعملاء استعراض المنتجات وطلبها، ويوفر لوحة إدارة لمحتوى المتجر والمنتجات والطلبات.

## المزايا

- استعراض المنتجات والتصنيفات والبحث والترتيب.
- سلة مشتريات وإتمام الطلب.
- خيارات ألوان وخامات بحسب إعدادات المنتج.
- إدارة مناطق التوصيل ورسومها والشحن المجاني.
- لوحة لإدارة المنتجات والتصنيفات والطلبات وإعدادات المتجر.
- واجهة عربية متجاوبة باتجاه RTL.

## التقنيات

- Next.js
- React
- TypeScript
- Supabase
- Vitest

## المتطلبات

- Node.js وnpm.
- مشروع Supabase وإمكانية الوصول إلى بياناته.

## الإعداد والتشغيل محليًا

1. افتح الطرفية داخل مجلد المشروع.
2. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

3. أنشئ ملف الإعداد المحلي بنسخ `.env.example` إلى `.env.local`:

   ```powershell
   Copy-Item .env.example .env.local
   ```

4. أضف بيانات اتصال Supabase إلى `.env.local`. لا ترفع هذا الملف إلى GitHub ولا تشارك مفاتيحه.
5. جهّز قاعدة البيانات باستخدام `supabase/schema.sql`، ثم طبّق ملفات `supabase/migrations/` بالترتيب. يمكن استخدام `supabase/seed.sql` لإضافة بيانات تجريبية.
6. شغّل التطبيق:

   ```bash
   npm run dev
   ```

7. افتح [http://localhost:3000](http://localhost:3000).

## فحوصات المشروع

```bash
npm run lint
npm test
npm run build
```

## الأمان

- لا تضع مفاتيح أو كلمات مرور أو بيانات سرية في الملفات المرفوعة.
- ملف `.env.local` مخصص للإعداد المحلي ومستثنى من Git.
- راجع سياسات الوصول والتخزين في Supabase قبل نشر التطبيق.
